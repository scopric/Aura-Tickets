1. Introducao
O frontend da Aura esta visualmente 95% completo, mas existem melhorias criticas que precisam ser
feitas antes do lancamento. Este documento lista tudo que precisa ser melhorado no frontend — desde
pequenos ajustes UX ate grandes features ausentes.
Principais Problemas Identificados
1. Carrossel de eventos na Home nao funciona — dados estaticos, sem scroll automatico
2. 90% das paginas usam mock — necessario conectar a APIs Supabase
3. Sem responsividade mobile em varias paginas do produtor
4. Sem skeleton loading — tela fica em branco enquanto carrega
5. Sem tratamento de erro — APIs falham = tela quebra
6. Sem infinite scroll — listas grandes carregam tudo de uma vez
7. Sem PWA — nao funciona offline, nao tem install prompt
8. Sem SEO — meta tags, Open Graph, structured data
9. Sem analytics — nao rastreia comportamento do usuario
10. Semdark mode — so tema claro disponivel

4. Estrutura de Estado Recomendada
7
4. Estrutura de Estado Recomendada
Atualmente o estado e gerenciado via React Context (AuthContext apenas). Para escalar, recomenda-
se:
4.1 Zustand para Estado Global
Por que Zustand e nao Redux?
Menos boilerplate: Zustand = 5 linhas de setup. Redux = 50+
Menor bundle: Zustand ~1KB. Redux ~7KB
TypeScript nativo: Tipagem automatica sem configuracao
Middleware: persist (localStorage), devtools (Redux DevTools)

4.3 React Query (TanStack Query)
Para gerenciamento de dados do servidor, usar TanStack Query v5:
Cache automatico: Dados cacheados por tempo configuravel
Stale-while-revalidate: Mostra dados antigos enquanto busca novos
Background refetch: Atualiza dados automaticamente
Optimistic updates: Atualiza UI antes da confirmacao do servidor
Retry automatico: Tenta novamente em falhas de rede
Devtools: Inspector de cache e queries

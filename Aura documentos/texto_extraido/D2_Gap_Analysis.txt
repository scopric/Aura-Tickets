1. Introducao ao Gap Analysis
O frontend da Aura tem 66 paginas e 82+ componentes implementados visualmente. Porem, 90%
operam com dados mock (fakes). Este documento identifica, pagina por pagina e funcionalidade por
funcionalidade, exatamente o que falta ser feito para tirar a plataforma do mock e coloca-la em
producao.
Resumo dos Gaps Identificados
Backend: 0 APIs — todas as 66 paginas precisam de endpoints
Banco de Dados: 0 tabelas — necessario criar 25+ tabelas no Supabase
Autenticacao: Mock hardcoded — necessario Supabase Auth
Pagamentos: Mock — necessario integrar Stripe + Woovi
Upload de Arquivos: Nao implementado — necessario Supabase Storage
Notificacoes: Nao implementado — e-mail + push
POS Cashless: Nao existe — necessario criar do zero
White Label: Nao existe — necessario criar do zero
Split de Pagamentos: Nao existe — necessario Stripe Connect

4. Resumo e Priorizacao
4.1 Prioridade P0 (Lancamento — Semanas 1-4)
14 tabelas + 4 Edge Functions + 3 integracoes
1. Criar tabelas users, events, ticket_types, tickets, orders, order_items, coupons, payments,
check_ins, customers, producer_balances, withdrawals, notifications, platform_settings
2. Configurar Supabase Auth (e-mail + Google OAuth)
3. RLS em todas as tabelas
4. Storage buckets (event-images, avatars, producer-logos)
5. Edge Functions: stripe-create-payment, stripe-webhook, woovi-create-pix, woovi-webhook,
send-email, check-in-validate
6. Integrar Stripe Connect e Woovi
7. Conectar frontend as APIs Supabase
Esforco estimado: 4 semanas (1 desenvolvedor full-time)
4.2 Prioridade P1 (MVP Completo — Semanas 5-8)
11 tabelas + 3 Edge Functions + features
1. Tabelas: event_images, seating_maps, seating_reservations, tasks, timeline_events, communications,
interest_list, event_branding, affiliates, affiliate_conversions, certificate_templates
2. Edge Functions: generate-certificate, withdrawal-process, affiliate-track, communication-send
3. Features: galeria, CRM completo, planejador, certificados, afiliados, comunicacao, white label basico
Esforco estimado: 4 semanas
4.3 Prioridade P2 (Features Avancadas — Semanas 9-16)
5 tabelas + features avancadas
1. Tabelas: menu_items, faq_items, crm_activities, ticket_transfers
2. POS Cashless (sistema completo de bar)
3. Marketplace de produtos
4. Rede social (feed + stories)
5. Maquinas de cartao
